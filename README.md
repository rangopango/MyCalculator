# MyCalculator

A simple Android calculator app built with **Kotlin** and **Jetpack Compose**, featuring a clean interface and a custom 3D app icon.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Chained calculations with multiple numbers
- Decimal number support
- Operator precedence for multiplication and division
- Percentage and sign-change buttons
- Backspace and clear functions
- Dark theme with a custom calculator interface

## Built With

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3

## Installation

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Connect an Android device or start an emulator.
5. Click **Run** to build and install the app.

## Project Structure

- `app/` — application source code and resources
- `gradle/` — Gradle wrapper configuration
- `build.gradle.kts` — project build configuration
- `settings.gradle.kts` — project settings
